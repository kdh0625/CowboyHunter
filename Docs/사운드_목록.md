# 사운드 목록

게임 코드에서 소리를 내는 곳과 연결할 파일을 정리한 표입니다.

## 파일 넣는 방법

1. 효과음은 `Assets/_Project/Audio/Sfx/`, 배경음은 `Assets/_Project/Audio/Music/`에 넣습니다.
   - 효과음: 자동으로 **모노, Decompress On Load, ADPCM** 설정
   - 배경음: 자동으로 **Streaming, Vorbis(품질 0.7)** 설정
   - 원본은 **WAV**를 권장합니다. MP3를 넣으면 한 번 더 압축되어 음질이 떨어집니다.
2. `Assets/_Project/Resources/SoundLibrary.asset`을 선택하고, 인스펙터에서 해당 칸에 파일을 끌어다 놓습니다.
   - 효과음 칸에 파일을 여러 개 넣으면 재생할 때마다 무작위로 고릅니다.
   - `volume`: 소리 크기, `pitchJitter`: 재생할 때마다 음높이를 조금씩 흔드는 정도
3. 비어 있는 칸은 재생하지 않습니다. 필요한 것부터 하나씩 채우면 됩니다.

## 새 소리를 추가하려면

`Assets/_Project/Scripts/Audio/SoundIds.cs`의 목록 **맨 끝**에 이름과 번호를 추가하고, 원하는 곳에서 `Sound.Play(SoundId.새이름)`을 부릅니다.
기존 번호를 바꾸면 이미 연결한 파일이 다른 칸으로 옮겨지므로 바꾸지 마세요.
