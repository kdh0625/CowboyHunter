## 9. 난이도에 영향을 주는 규칙 결정 (구현 시 임의로 정함)

| 규칙 | 현재 동작 | 확인 |
|---|---|---|
| 드로우 중 탄이 바닥날 때 | 남은 탄을 뽑고, 버린 더미를 섞어 나머지를 이어서 뽑음 | [ ] |
| 발사 중 타겟이 죽으면 | 남은 탄은 살아 있는 다음 적에게 | [ ] |
| 발사 조건 | 손에 탄이 있으면 6칸을 모두 채워야 발사 가능 | [ ] |
| 보호막 초기화 | 내 것은 내 턴 시작, 적 것은 적 턴 시작 (적 방어는 내 다음 턴까지 유지) | [ ] |
| 화상 / 독 | 화상은 1씩 감소, 독은 감소 없음 | [ ] |
| 약화 (저주탄) | 적의 다음 공격 한 번에만 적용, 타격마다 감소, 공격 후 사라짐 | [ ] |
| 여러 번 공격 (×N) | 타격마다 보호막을 따로 깎음 | [ ] |
| 불새탄 판정 | 발사 순간 대상이 화상 상태인지 (같은 턴 앞 슬롯의 화염탄도 인정) | [ ] |
| 관통탄 연계 | 직전 슬롯이 화염탄이면 +4 | [ ] |
| 유물 획득 시 | 해당 부위가 비어 있으면 자동 장착, 아니면 보관함 | [ ] |
| 상점 방문 | 마지막 보스를 제외한 모든 승리 후 (보스 승리 후 포함) | [ ] |
| 저장 시점 | 게시판·상점에서 자동 저장. 전투 중 종료하면 전투 전 게시판으로 돌아감 → 불리한 전투를 껐다 켜서 다시 할 수 있음 (수배서는 그대로) | [ ] |
